## 13. Common Issues & Solutions

**Issue:** App rejected for "Missing Privacy Disclosures"  
**Solution:** Ensure all data types are declared in App Privacy Information tab

**Issue:** App rejected for "Excessive Permissions"  
**Solution:** Minimize permission requests; only ask when feature is actually used

**Issue:** App rejected for "Misleading Description"  
**Solution:** Ensure description matches actual app functionality exactly

**Issue:** Build fails to upload**  
**Solution:** 
- Verify Certificate and Provisioning Profile are valid
- Use Xcode's automatic signing
- Check bundle identifier matches App Store Connect

**Issue:** Location permission denied on iOS**  
**Solution:** 
- Request permission at appropriate time (when bus tracking is first used)
- Use NSLocationWhenInUseUsageDescription (not always)
- Test on real device (simulator behavior differs)
